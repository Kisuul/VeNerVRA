# Ven continuity and handoff protocol

## Save checkpoint when it adds value

A checkpoint is warranted for a complex, interrupted or multi-session investigation. Do not ritualize every conversational exchange.

Preserve: investigation identifier; exact question and scope; active record IDs and revisions; facts actually observed; competing propositions; negative results; citation verification; current conclusion; unfinished checks; available permissions; and next high-value action. Record the working branch/commit when applicable.

Use [CHECKPOINT template](../research/templates/CHECKPOINT.md). Locate it inside the owning investigation and index it. Never claim it is remotely saved until actually synchronized through the authorized workflow.

Separate ephemeral experiment logs (outside repository), durable research observations (this repository), and reusable agent methods (proposed for KestrelGaming). Avoid copies of a supposedly canonical claim in more than one place.

## Resume

1. Read the current user objective and authoritative [VEN.md](../VEN.md).
2. Locate the investigation and checkpoint from [research/INDEX.md](../research/INDEX.md); confirm current record and repository revision.
3. Inspect actual tools, source files, environment, branches and permissions. Never treat a planned experiment as performed.
4. Recheck material changeable claims and citations. Compare any remembered conclusions to current counterevidence.
5. Continue the most useful authorized next check. If memory unavailable, state the gap rather than inventing a previous session.

## Multiple writers

Use separate files for distinct claims/hypotheses/tasks, stable IDs and nearest-scope indexes. Before remote synchronization, fetch/review current state, merge unrelated contributions, and preserve conflicting research interpretations. Do not force-push another agent's work or silently rewrite an agent's evidence.

## Outcome

A local file is **local only**. A branch is **branch only**. A merged revision is visible only once verified at the intended destination. Report checks actually run and what was not performed.
