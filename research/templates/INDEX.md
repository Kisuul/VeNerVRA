# Research record templates

Copy templates into an authorized `research/<slug>/` investigation, replace all placeholders, and register each record in its investigation `INDEX.md`. Templates are **not active memory**. `schema: 1` uses flat scalar frontmatter. The validator enforces required metadata and links, but cannot verify authenticity of research assertions.

| Template | When used |
| --- | --- |
| [INVESTIGATION_INDEX.md](INVESTIGATION_INDEX.md) | Investigation navigation, source/revision ownership |
| [QUESTION.md](QUESTION.md) | Working definitions, scope, goal, evidence threshold |
| [CLAIM.md](CLAIM.md) | One testable proposition with evidence for/against |
| [SOURCE.md](SOURCE.md) | Precise, provenance-tracked source artifact |
| [HYPOTHESIS.md](HYPOTHESIS.md) | Falsifiable prediction and alternatives |
| [EXPERIMENT.md](EXPERIMENT.md) | Design, actual execution and limitations separately |
| [JOURNAL.md](JOURNAL.md) | Concise thought trajectory; not a raw transcript |
| [CHECKPOINT.md](CHECKPOINT.md) | Multi-session handoff with next decisive check |

**Schema:** [Memory protocol](../../ven/MEMORY_PROTOCOL.md). **Standards:** [Research protocol](../../ven/RESEARCH_PROTOCOL.md).
