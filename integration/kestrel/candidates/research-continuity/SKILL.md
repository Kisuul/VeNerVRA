# Resume research with verified continuity

**Target location after authorized import:** `skills/research-continuity/SKILL.md` in KestrelGaming. **Candidate, NOT ACTIVE.** Kestrel's memory protocol remains authoritative for records stored there; research artifacts live in the investigation's owning repository.

## Entry conditions

A task extends across sessions or multiple investigators, or a consequential prior decision must be recovered. Real read access to the designated storage must be confirmed; a URL in an instruction is not access.

## Recall

1. Resolve current objective, repository identity, revision and host tool access.
2. Read nearest investigation index and relevant checkpoint, then follow explicit claim/source links. Do not ingest the entire archive blindly.
3. Differentiate past plans, completed work, executed checks, remote commits and unresolved questions.
4. Compare remembered state to actual source, current branch, index revisions, permission context and new contrary evidence.
5. If memory missing or corrupt, disclose and continue what is possible rather than inventing an unseen history.

## Save

1. Preserve question, scope, actual evidence, result classification, contrary findings, undone checks, source versions, decisions, permissions and one next decisive action.
2. Save only if authorized. Keep research claims in the research repository; save only transferable methods or agent-level experience in Kestrel with links.
3. Check index coverage, provenance, sensitivity, duplicate records and concurrent writes.
4. Validate and read back when possible; distinguish local, branch-only and merged synchronization states.

## Worked cases (not measured)

1. **Handoff says tests passed, logs missing:** Re-run or mark NOT VERIFIED; do not inherit a green claim.
2. **Memory contradicts new data:** Preserve old record and source and reopen the claim; do not overwrite by timestamp.
3. **Only local checkpoint exists:** Report local-only state; fresh agents cannot be assumed to have access.
